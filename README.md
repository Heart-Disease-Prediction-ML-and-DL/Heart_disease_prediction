# Heart Disease Prediction Using Machine Learning and Deep Learning

A machine learning and deep learning-based web application for predicting the risk of heart disease using clinical patient data. The project compares multiple machine learning algorithms and deep learning models and provides an easy-to-use web interface for heart disease risk prediction.

## 🚀 Live Demo

**Try the deployed application:**
[Heart Disease Prediction – Live Demo](https://heart-disease-prediction-blush.vercel.app/)

## 🧠 Project Highlights

* Machine Learning and Deep Learning approaches
* Heart disease prediction using clinical data
* Artificial Neural Network (ANN) model
* Convolutional Neural Network (CNN) comparison
* Decision Tree-based interface for non-technical users
* Doctor/technical interface for model-based prediction
* Web-based prediction system
* Developed using Python, Flask, TensorFlow, and Scikit-learn

## 🛠️ Technologies

* Python
* Flask
* TensorFlow / Keras
* Scikit-learn
* Pandas
* NumPy
* HTML, CSS, JavaScript

## 📊 Dataset

The project uses a locally collected heart disease dataset from Swat, Pakistan, containing clinical and patient-related features for heart disease prediction.

## 📌 Project Purpose

The main objective of this project is to explore how machine learning and deep learning techniques can be applied to heart disease risk prediction and to develop a practical web-based prediction system.
